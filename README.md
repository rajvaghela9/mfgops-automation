# ib.python-template
Scaffold template for new Python repos onboarded via BloxPortal. Seeds GitHub Actions CI, Makefile, Dockerfile, Helm chart, and standard Python project layout — selected as the scaffold option when requesting a new repo.

## Newly scaffolded from this template?

CI fails on the `scaffold-guard` job until the placeholders are renamed, so no
placeholder image or chart gets published. Run `make scaffold-check` for the
exact commands, or read the job log. Replace this section when you rewrite the
README for your service.
